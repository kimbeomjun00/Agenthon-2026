# VSpecial2 자가점검·후속 실험 — 2026-10-13

결론: CPI_ALL 전용 혼합 후보는 유망하지만, 아직 VSpecial을 안정적으로 이겼다고 말할 수 없다. 기본 모델은 재현된 코드 오류만 수정한 VSpecial2 `price`로 유지하고, 새 예측 모델은 선택 가능한 연구 후보로 제공한다. 제출한 ZIP, 등록 이미지, Codabench 제출 내용은 변경하지 않았다.

## 무엇을 만들었나

- `VSpecial2/`: 독립된 수정본. 기본 `--mode price`는 일반적인 정상 입력에서 기존 VSpecial 수치 예측을 그대로 유지한다.
- `--mode cpi_soft`: CPI_ALL에만 과거 구간으로 선택한 후보들의 혼합을 적용한다. 다른 계열은 수정된 기존 모델을 유지한다. 연구용 옵션이다.
- `soft`, `calibrated`, `geometric`, `term`, `daily_calibrated`: 이번에 실험한 대안 모델. 자동으로 기본값에 적용하지 않는다.
- `VSpecial_baseline/`: 실제 제출 이미지와 소스 해시가 일치하는 비교 기준.
- `research/`: 실행·검증·분석 코드, 재현 안내, 집계 결과, 입력 데이터 해시. 원시 패널·개별 예측·정답값·팀 인증 파일은 포함하지 않는다.

혼합은 단순히 평가표에서 가장 좋은 모델을 고정한 방식이 아니다. 각 실행의 cutoff 이전에 완전히 끝난 예측 구간으로 후보 가중치를 정하며, 기본 모델 비중과 최소 개선·승률 조건을 둔다. 다만 CPI만 혼합하도록 제한한 결정 자체는 이번 비교 결과를 본 뒤의 추가 연구이므로 독립 검증이 더 필요하다.

## 자가점검에서 확인하고 수정한 것

| 점검 | 제출 모델에서 재현한 현상 | 수정본 |
| --- | --- | --- |
| 같은 월, 서로 다른 관측 날짜 | CPI가 1일, Core가 15일이면 월별 공통 차분 부족으로 실패 | 원래 관측 날짜로 cutoff를 먼저 적용하고 같은 달끼리 정렬 |
| 과거 내부 데이터 공백 | 최신 관측이 있어도 과거 긴 공백의 변화가 하루 충격처럼 포함됨 | 공백을 가로지르는 차분 제외, 각 자산의 현재 관측값 유지 |
| House에 전달하는 기준값 | 실제 관측값 대신 예측 중앙값, 최근·전체 변동성이 동일하게 전달됨 | 실제 관측값과 실제 변동성·단위·예측구간 정보 전달 |
| 극단적 음수 방향 텍스트 시나리오 | 양수 FX·물가지수의 변환이 0 아래로 갈 위험 | 같은 시나리오 배정을 유지하는 양수 로그공간 대체 변환 |

합성 공백 테스트의 63일 예측 표준편차는 6.1339 → 0.0743이었다. 이는 공백 처리 오류 재현값이지 실제 금융계열의 정확도 향상 수치가 아니다. 월 중복 관측 거부는 내부 함수에도 추가했지만, 기존 공식 CLI도 이미 중복을 거부했으므로 새로 발견한 제출 형식 오류라고 주장하지 않는다.

최종 이미지에서 코드 테스트 **24/24** 통과. 기본 모드와 CPI 전용 후보 각각 공개 과제 **103/103**의 공식 출력 게이트 통과. 기본 모드는 네 과제 유형에서 네트워크 차단·읽기 전용 컨테이너 실행 **4/4** 통과, 정확히 3개 출력 파일을 생성했다. 출력 검사에는 정답이 없으므로 이것은 예측 정확도 검증이 아니다. 103개 검사는 최종 House 문맥 설명 필드 추가 직전에 실행했으며, 수치 예측 코드는 이후 변경하지 않았다. 최종 문맥을 포함한 24개 코드 테스트는 다시 통과했다.

## 해석상 중요한 한계

1. 개발 기간은 2006–2019년, 후속 평가 기간은 2020–2024년이다. 후속 기간은 이전 연구에서 이미 살펴봤으므로 완전히 새로운 holdout이 아니다.
2. 기본 평가 시점은 금리 19개, FX 19개, 요인 17개, macro 5개다. CPI 기간 변경 검사는 8개다. 같은 기간 내 미래 창은 겹치지 않도록 했지만 서로 다른 기간 검사 사이에는 겹침이 있다.
3. 평가에서는 2,000개 경로와 난수 seed 42·77을 사용했다. seed를 먼저 같은 평가 시점끼리 평균했다. 두 seed를 독립 사례 두 개로 세지 않았다.
4. 공식 CRPS·variogram·tail pinball 함수를 사용했지만, 변동성 정규화와 참조 분포 기반 로컬 종합손실은 **공식 M0 정규화가 아니다**. Codabench 점수를 추정한 것이 아니다.
5. CPI 단독 개선의 탐색적 연도 블록 구간은 약 +0.97%~+31.41%지만, 적은 시점·적은 연도와 사후 후보 선택을 보정하지 않은 구간이다. 기간 변경 악화가 있어 확정적인 우월성 근거로 쓰지 않는다.
6. Macro는 단일 수정 이력 데이터다. 발표 당시 빈티지별 성능이 아니며, 실제 House 응답의 정확도·텍스트 효과도 이번 로컬 실험으로 검증하지 못했다. House 모의 응답 검사는 연결·형식만 확인한다.

## 지금 권장하는 선택

일단 이미 제출한 VSpecial의 Codabench 결과를 확인하자. 이번 패키지는 **제출용 ZIP이 아니라 연구·수정 소스 ZIP**이다. 다음 제출 후보로는 재현된 입력 처리 수정본을 우선 검토하고, CPI 혼합은 실제 평가의 취약 계열·기간을 확인한 뒤 별도 비교하는 편이 타당하다. 아직 전체적으로 더 강한 모델을 만들었다고 단정하지 않는다.

`RESULTS_SUMMARY.csv`에는 위 판단의 세부 수치와 평가 범위를, `research/results/*_analysis/`에는 자산별 결과와 불확실성 집계를 담았다. `MANIFEST.json`으로 모든 파일의 해시를 확인할 수 있다.

재현은 `research/REPRODUCE.ps1 -RepositoryRoot <V11/units가 있는 저장소 경로>`로 시작한다. 실행 전 Docker Desktop이 준비되어 있어야 한다. 기본 모델·CPI 옵션 모두 로컬 전용 태그이며 제출된 이미지 digest를 교체하지 않는다.
